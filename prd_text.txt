6.3 Security Requirements
•     Webhook delivery with exponential backoff, HMAC-SHA256 signature verification.
•     Idempotency keys required on all POST endpoints for payment and order creation.
•     Rate limiting: 100 req/min per IP (public), 1000 req/min per authenticated tenant.
•     OpenAPI 3.1 spec auto-generated and hosted at /docs; Postman collection exported.
•     RESTful APIs versioned under /api/v1/; tRPC for internal type-safe calls.

14.2 Document History
•     LTV — Customer Lifetime Value: predicted revenue from a customer over their relationship.
•     RPO — Recovery Point Objective: max acceptable data loss in time units.
•     RTO — Recovery Time Objective: max acceptable downtime after an incident.
•     RBAC — Role-Based Access Control: permissions tied to user roles, not individuals.
•     PWA — Progressive Web App: web app installable on mobile with offline support.
•     KDS — Kitchen Display System: screen in the kitchen showing live order queue.
